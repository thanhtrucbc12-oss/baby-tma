# Проверка выпуска: 4 сентября 2026

## Изменения

- Перенесён одобренный цветной макет: коралловый главный блок, три быстрых действия, цветные события, обновлённые дневник, помощник и профиль. Тёмный текст на коралловом фоне выбран для контраста.
- «Уснул» запускает таймер, «Проснулся» завершает и сохраняет сон. Ночное пробуждение остаётся отдельным действием в дневнике.
- Поля профиля занимают доступную ширину, нижние пункты доступны над навигацией. Основные иконки профиля заменены на Lucide.
- Карточка с действием «Открыть дневник» теперь открывает дневник, а не статьи.
- Синхронизация передаёт настройку напоминаний как boolean и восстанавливает ожидаемый клиентом формат. Применяется отзыв согласия на ИИ, обновляются поля режима и сбрасывается устаревший план в памяти.
- Локальные профили разделены по аккаунтам. При смене аккаунта прежние несинхронизированные записи сохраняются отдельно и восстанавливаются при возвращении. Токены входа и платёжные ключи в эти копии не включаются.
- Ответ синхронизации, пришедший после выхода, отбрасывается; смена аккаунта перезагружает страницу, очищая чат и таймеры из памяти.

## Проверено

- Полный Node-набор: 34 результата тестов, без ошибок (27 файлов, часть содержит собственные группы проверок).
- ИИ-сервис: 14 Python-тестов, без ошибок. Проверены HMAC, приватность контекста, обработка опасных запросов, fallback и изоляция провайдера.
- Playwright/Chrome: сохранение сна после перезагрузки, изменение профиля, основные четыре экрана при ширине 320, 375, 844 и 1440 px, уменьшенное движение, увеличенный текст, доступность последнего пункта профиля.
- Открытие форм Premium, партнёрского раздела, базы знаний и ритуала; изоляция двух синтетических аккаунтов и выход. Тесты блокируют запись тестовых данных и платежей в production.
- Тесты настоящего модуля авторизации: корректная/поддельная/просроченная подпись Telegram, хеширование сессии, отзыв/истечение сессии, привязка к пользователю.
- Production: девять защищённых API возвращают 401 без авторизации; sync-data отклоняет поддельную Telegram-подпись (401) и посторонний Origin (403).
- Код миграций включает RLS для таблиц данных, оплат, сессий и партнёров. Прочитаны проверки владельца в sync-data и partner-portal, серверная проверка платежей/возвратов через YooKassa.
- Проверка шаблонов секретов в текущих отслеживаемых исходниках не обнаружила ключей. Это не скан всей Git-истории и не доказательство отсутствия любых секретов.
- На VPS активны baby-agent и baby-hermes-proxy; health-check возвращает ok и provider_configured.

## Границы проверки

- Это инженерная проверка, не независимый пентест и не гарантия отсутствия уязвимостей.
- Реальные новые платежи, возвраты, Stars-продление и две партнёрские оплаты не выполнялись. Проверялись код, тестовые сценарии и отказ в неавторизованном доступе. Ранее пользователь подтвердил реальную оплату YooKassa и возврат.
- Без текущего административного доступа не проверены свежий Supabase Security Advisor, состояние cron/доставок уведомлений и реальные начисления партнёрам. Миграции на диске не доказывают состояние production-БД.
- GitHub Pages отдаёт HSTS, но не HTTP CSP/frame-ancestors и nosniff. Meta CSP не заменяет защиту от встраивания. Для этих заголовков нужен хостинг с управляемыми ответами.
- Inline-обработчики остаются, поэтому CSP пока допускает unsafe-inline. Их перенос во внешние обработчики является отдельным усилением защиты.
- Локальные копии аккаунтов не зашифрованы: это защита от случайного смешивания данных, не от человека с доступом к профилю браузера. Команда удаления данных устройства удаляет и локальные копии.
- Старый отозванный бот-токен в исторических коммитах не переписывался. Нужен согласованный отдельный шаг для очистки истории.
- Нагрузочный тест на 100 одновременных платящих пользователей и внешний модельный ответ от имени реального пользователя в этой проверке не выполнялись.

## Воспроизведение

```sh
node --test tests/*.test.js tests/*.test.mjs
NODE_PATH=/path/to/node_modules node tests/browser-smoke.cjs
node tests/production-smoke.cjs
```

Для browser-smoke нужен локальный HTTP-сервер на 127.0.0.1:8765 (или QA_URL), установленный Chrome и Playwright. Скриншоты: QA_OUTPUT или /private/tmp/baby-mode-qa.
