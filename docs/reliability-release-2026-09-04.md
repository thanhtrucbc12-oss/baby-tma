# Исправления надёжности, 2026-09-04

## Изменения

- Аналитика больше не записывает профиль ребёнка и согласие на уведомления, не отправляет имя/дату рождения. Локальная очередь привязана к аккаунту; старые неразмеченные события не переотправляются. Пакеты ограничены 20 событиями, удаляются только подтверждённые ID. Поздний ответ не очищает очередь другого аккаунта.
- Старые записи дневника без `_updatedAt` сохраняются с базовой версией. Удаление применяется только при настоящем tombstone.
- BEFORE UPDATE триггеры в PostgreSQL защищают версии профиля, дневника, настроек и согласия от устаревшего конкурентного `upsert`.
- YooKassa: запись оплаты, периода, подписки и комиссии объединена в транзакцию с блокировкой по платёжному аккаунту. Дубликат не продлевает доступ повторно. Возврат и отмена комиссии также атомарны. Позднее уведомление об успехе не восстанавливает возвращённую оплату.
- Согласие на уведомления хранится в `notification_settings` и передаётся через подтверждаемую синхронизацию, а не аналитику. Бот сохраняет часовой пояс. Отключение отменяет ожидающие задания. Планировщик и отправитель проверяют согласие и Premium на сервере. Старые планы не заменяют новые; отправленные задания не переотправляются при повторе плана.
- Добавлены тесты на PostgreSQL-движке PGlite с искусственными отказами реальных SQL-записей. Это дополняет, а не заменяет проверки на рабочем PostgreSQL.
- GitHub Pages переведён с прямой публикации ветки на workflow: выпуск зависит от успешного набора тестов, SQL-проверок, сборки функций и браузерных сценариев. Адрес сайта не изменён.
- Помощник: вместо отсутствующей `stealth/ox-alpha` используется `upstage/solar-pro4:free`. Проверяются нулевая цена и наличие модели в официальном каталоге Nous через локальный прокси; положительная проверка кешируется на 300 секунд. Неизвестная/ненулевая цена блокирует запрос. Изоляция сервиса с доступом только к localhost сохранена. Резервный ответ не кешируется на полчаса и явно обозначается в интерфейсе как ответ базы знаний.

## Эксплуатационные ограничения

- Нельзя гарантировать отсутствие будущих ошибок или постоянную доступность внешней бесплатной модели. При недоступности используется база знаний; платная модель автоматически не включается.
- Telegram-сообщение, уже переданное внешнему API, нельзя отменить задним числом. Проверка согласия выполняется перед отправкой, очередь отменяется в БД.
- GitHub Pages по-прежнему не даёт настроить полный набор HTTP security headers. Переезд на другой домен/хостинг не выполнялся.
- Реальные Stars-платежи, новые списания и выплаты партнёрам в этой сессии не выполнялись. Ранее проведённые пользователем YooKassa-оплата и возврат не выдаются за новые тесты.
- Версионность защищает от отката новым запросом старого состояния; независимые изменения одного дня пока используют выбор последней версии дня, а не поэлементное совместное редактирование.
